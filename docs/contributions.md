## 주요 문제 해결의 예

### 새 요청의 저장 성공 여부 오판 방지

**상황:** Agent 테스트에서 기존 DB 행이 존재한다는 사실과 이번 요청이 실제로 저장되었다는 사실이 혼동될 수 있었습니다.  
**개인 기여:** 리뷰/검증 과정에서 결함을 확인하고 수정 요청을 남겼습니다.  
**경계:** 저장 verifier의 실제 패치는 다른 팀원이 구현했으므로 개인 코드 수정 성과로 기재하지 않습니다.

### 모델 후보 선정과 반례 기록

**상황:** 빠른 응답·비용·출력 형식의 일관성을 함께 판단할 필요가 있었습니다.  
**개인 기여:** 다수 후보에 동일 합성 과제를 적용해 비교하고 근거·제약을 기록했습니다.  
**경계:** 후보 선정이나 합성 평가 통과가 곧 실제 사용자 품질 검증은 아닙니다.
